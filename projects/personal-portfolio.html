Overview

My personal digital portfolio brings together my software engineering background, research work and STEM teaching experience. Created during the Khazanah Nasional K-Youth programme, it now presents my background and selected work through a pastel desktop-inspired interface.

Purpose

The website provides one place to explore my education, experience, awards and skills, read about selected projects, and find my email and professional profiles.

Technologies

Semantic HTML structures the pages, shared CSS provides the responsive layout and visual design, and JavaScript controls the mobile menu and active-section navigation. The hero PC is drawn with local SVG, while photographs and folder artwork are stored as local image assets.

Features

  • Responsive homepage sections for About, Portfolio, Experience, Awards, Skills and Contact.
  • macOS-style content windows, a pastel PC illustration and separate project detail pages.
  • A mobile menu with keyboard controls and navigation that follows the visible section.
  • An alternating experience timeline that stacks on smaller screens.
  • Visible keyboard focus, skip links and reduced-motion support.
  • Direct contact and repository links, with no contact form or backend required.
